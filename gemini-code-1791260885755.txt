CIRCLE QUEST — PROTOTYPE
=========================

Cara menjalankan:
1. Simpan file index.html, style.css, dan script.js dalam satu folder.
2. Buka index.html di browser (Chrome/Edge/Firefox).
3. Masukkan nama siswa untuk memulai permainan.
4. Mode Guru dapat dibuka melalui tombol "⚙ Mode Guru" di footer.

Fitur:
- 5 level berjenjang materi Persamaan Lingkaran.
- Setiap sesi mengambil 5 soal acak dari bank soal per level.
- Format soal mendukung penulisan formula matematika LaTeX via MathJax.
- Minimal 80% jawaban benar untuk membuka level berikutnya.
- Perhitungan skor, bonus kecepatan waktu, review hasil, dan simpan data otomatis di localStorage browser.
